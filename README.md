## 住宅 VPS 和住宅代理，买到的是两种东西

住宅 VPS 交付的是一台完整虚拟机：Windows 给 RDP 桌面，Linux 给 SSH，CPU、内存、硬盘都归你，按月固定计费，系统里装什么由你决定。住宅代理交付的是一串 `IP:Port:User:Pass` 凭据，按 GB 流量或按并发线程计费，没有操作系统，也不能在它上面装软件。

判断方法很直接：要在远程桌面上开 AdsPower、Multilogin 这类指纹浏览器、要挂桌面版社媒客户端、要跑 Claude Computer Use 这种带界面的 AI 代理，只有 VPS 能做。要写爬虫采集几千个页面、需要成百上千个 IP 轮换，代理更便宜也更省事。两者的价格单位都不一样，比价没有意义。

还有两个经常被混用的标签：

**“原生 IP”不等于“住宅 IP”。** CstoneCloud 的价目页把这两条线分开卖，同样是 9929 回程，原生 IP 档折后 ¥28/月，住宅双 ISP 档 ¥44/月，差了将近 40%（该页标注的是促销折算价，对应活动已于 2026 年 9 月 30 日结束，这里只看量级）。商家页面写"原生"，说明这个 IP 注册在当地、归属地干净；风控数据库里会不会显示成 Residential，是另一回事。

**“双 ISP”目前是商家口径。** 常见说法是这枚 IP 同时被两家运营商注册，因此在风控库里更容易被判为住宅而非数据中心。这个说法在 Sixtynet 的第三方测评里能看到对应结果（ipinfo 显示双 ISP），但没有公开的行业标准文档，把它当成"商家这么描述、实测结果吻合"更稳妥。

**静态还是动态，官网没写。** 住宅系列页面只标了 Residential IP，没有说明 IP 在订阅期内是否固定。要长期挂同一个社媒账号、保持登录状态，这一点必须先问客服确认。需要大量 IP 轮换的采集类业务，本来也不该买 VPS。

## IP 是不是真住宅，下单当天 30 分钟能验完

三步，全在浏览器里做：

1. **ipinfo.io**：查这枚 IP 的 ASN Type 是不是 `ISP`，组织名是不是 AT&T、Cox 这类消费级运营商。显示 `hosting` 就说明是机房 IP，直接找客服。
2. **IPQualityScore**：看 Fraud Score 是否处于低位，Proxy Detected 是否为 False。
3. **ping0.cc**：看风险值，作为第三个独立数据源交叉。

Sixtynet 这边的第三方验证结果是有的。主机测评站在 2024 年 8 月测过 AT&T Mobility 那条线，ipinfo 显示为双 ISP，多个数据库判断为原生美国 IP、家宽属性，流媒体解锁表现好；2025 年 10 月又测了 Cox 那条，同样显示双 ISP。这些是别人买到的机器，不能替你手上这枚背书，但至少说明产品线和宣传是对得上的。

验证有两个已知的局限。新落地的 IP 段，第三方数据库可能还没更新完，ZoroCloud 在英国线上就明确提示过这一点，测出来是机房属性未必代表 IP 有问题，隔几天再测一次。另外同一枚 IP 在不同库里结论可能不一致，"住宅""ISP""原生"这些标签本来就没有统一口径，多查两个库、再拿目标平台实际登录一次，比盯单一分数有用。

也别指望买完就万事大吉。没有任何方案在所有情况下都不可检测，结果取决于目标站点、这枚 IP 的历史和你的操作行为，这一点连主打住宅 IP 的商家自己也是这么写的。

## 下单前的几个坑

**80/443 端口封闭是全线限制**，不是某个套餐的问题。官网给出的理由是 IP 风控。这意味着住宅系列只能做"人坐在桌面后面操作"的业务，任何需要对外提供网页服务的用途都得换产品线。

**退款条款要分产品看。** IRVINE-PRO 系列官网明写退款只退到网站余额，不退现金。住宅系列和 LAX 系列的退款政策官网上没有单独说明，下单前问清楚窗口期。这个品类的行业惯例本来就紧：CstoneCloud 给 24 小时无理由退款，前提是 IP 未封、每天限退一次，原路退回扣 10% 手续费；丽萨主机是 48 小时；ZoroCloud 部分住宅产品开通后直接不退款。也就是说，机器到手当天就得把 IP 检测跑完，别拖到第三天。

**换 IP 通常要花钱，而且换来的大概率同段。** CstoneCloud 的规则是新购机器被墙且零流量可免费换，其他情况收费，新 IP 多半还在同一个网段。频繁换 IP 本身会触发风控，对养号是负面操作。Sixtynet 的换 IP 政策官网没有写明，有需要直接问。

**回国线路决定体验上限。** 主机测评的测试数据显示，AT&T Mobility 那条线三网回程走 CN2，Cox 那条是电信和移动走 CN2、联通走 AS10099 + AS9929，国内访问属于有优化的那一类。但这是美国线的情况。英国、欧洲的住宅产品普遍不保证国内方向稳定，CstoneCloud 在英国线上就明确写着"建议自备中转"。买之前先确认你选的是哪个地区、回程走的什么线路。

**性能不是这条产品线的卖点。** 2024 年那篇测评对 AT&T 线的评价是 CPU 和 I/O 都偏弱；2025 年 Cox 线的 I/O 测到约 188MB/s，CPU 表现尚可。跑浏览器、账号操作、轻量脚本没问题，拿来跑重负载计算或者高并发服务是选错了产品。
